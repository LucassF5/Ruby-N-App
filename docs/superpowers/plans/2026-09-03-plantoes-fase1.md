# Plantões Fase 1 (Meus Plantões) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the demo `Post` CRUD with a `Plantao` (shift) CRUD — list, create, edit, delete — as the app's new home screen.

**Architecture:** Single new ActiveRecord model (`Plantao`) backed by a fresh `plantoes` table, replacing `posts` (dropped in the same migration). A `PlantoesController` with `index/new/create/edit/update/destroy` replaces `PostsController`. Views follow the existing Tailwind conventions already used by the posts views. No JS, no calendar widget, no new gems.

**Tech Stack:** Rails 8.1, SQLite, Minitest + fixtures, Tailwind (via `tailwindcss-rails`), `ruby_native` gem (unchanged in this plan).

**Spec:** `docs/superpowers/specs/2026-09-03-plantoes-fase1-design.md`

## Global Constraints

- Single-user app, no auth, no `user_id` scoping on `Plantao`.
- No remote backend/sync — SQLite only, nothing added here talks to a network service.
- Shifts are same-day only: `hora_fim` must be after `hora_inicio` (no overnight/midnight-crossing shifts in this phase).
- List view only — no calendar/month-grid UI in this phase.
- No reminder/notification code, columns, or jobs (Fase 2 is explicitly deferred).
- No `indisponibilidades` table or UI (Fase 3 is explicitly deferred).
- `Profile` tab/page and `config/ruby_native.yml` tabs stay exactly as they are — out of scope.

- [ ] **Step 2a: Add an irregular inflection for `plantao`/`plantoes`**

Rails' default English inflector pluralizes the class name `Plantao` to `plantaos`, not `plantoes` — there's no built-in "-ao → -ões" rule. Without this step, `Plantao.table_name` resolves to `"plantaos"`, which doesn't exist (the migration creates `plantoes`), and every model/controller test fails with `Could not find table 'plantaos'`.

In `config/initializers/inflections.rb`, uncomment and adapt the example block so the file reads:

```ruby
# Be sure to restart your server when you modify this file.

# Add new inflection rules using the following format. Inflections
# are locale specific, and you may define rules for as many different
# locales as you wish. All of these examples are active by default:
# ActiveSupport::Inflector.inflections(:en) do |inflect|
#   inflect.plural /^(ox)$/i, "\\1en"
#   inflect.singular /^(ox)en/i, "\\1"
#   inflect.irregular "person", "people"
#   inflect.uncountable %w( fish sheep )
# end
ActiveSupport::Inflector.inflections(:en) do |inflect|
  inflect.irregular "plantao", "plantoes"
end

# These inflection rules are supported but not enabled by default:
# ActiveSupport::Inflector.inflections(:en) do |inflect|
#   inflect.acronym "RESTful"
# end
```

This is a Rails initializer — it's picked up automatically the next time the app boots (including for `bin/rails test`), no separate load step needed.

- [ ] **Step 8: Implement the `Plantao` model**

Create `app/models/plantao.rb`:

```ruby
class Plantao < ApplicationRecord
  validates :data, presence: true
  validates :hora_inicio, presence: true
  validates :hora_fim, presence: true
  validate :hora_fim_depois_da_hora_inicio

  private

  def hora_fim_depois_da_hora_inicio
    return if hora_inicio.blank? || hora_fim.blank?

    errors.add(:hora_fim, "deve ser depois do horário de início") if hora_fim <= hora_inicio
  end
end
```

- [ ] **Step 6: Implement `PlantoesController`**

Create `app/controllers/plantoes_controller.rb`:

```ruby
class PlantoesController < ApplicationController
  before_action :set_plantao, only: [:edit, :update, :destroy]

  def index
    @plantoes = Plantao.order(:data, :hora_inicio)
  end

  def new
    @plantao = Plantao.new
  end

  def create
    @plantao = Plantao.new(plantao_params)

    if @plantao.save
      redirect_to root_path, notice: "Plantão criado."
    else
      render :new, status: :unprocessable_entity
    end
  end

  def edit
  end

  def update
    if @plantao.update(plantao_params)
      redirect_to root_path, notice: "Plantão atualizado."
    else
      render :edit, status: :unprocessable_entity
    end
  end

  def destroy
    @plantao.destroy
    redirect_to root_path, notice: "Plantão removido."
  end

  private

  def set_plantao
    @plantao = Plantao.find(params[:id])
  end

  def plantao_params
    params.require(:plantao).permit(:data, :hora_inicio, :hora_fim, :local, :observacao)
  end
end
```
